# analysis

- `PREREGISTRATION.md`: hypotheses, definitions, models and exclusions. **Commit it before running any outcome analysis**; the commit timestamp is the proof.
- `notebooks/`: exploration only. Nothing in a notebook is a result.
- `src/ekko_analysis/`: sessions, streaks, lane-opponent matching, Q1/Q2/Q3 models, with unit tests and a known-effect simulation.
- `results/`: tables and figures regenerated from one command.
